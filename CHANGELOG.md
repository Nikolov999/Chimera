# Changelog

## v1.0.0

Initial public source release.

Highlights:

- Cross-platform Windows, Linux and macOS live-host assessment
- Deterministic evidence and finding contracts
- Vulnerability, exposure, hardening and misconfiguration workflows
- Process, service, network, identity, filesystem, storage, container, persistence and secret-storage coverage
- Profiles, selection, suppression, baselines and assessment diffing
- Human-readable and machine-readable output workflows
- Built-in runtime/contract validation through `chimera doctor`

The public repository intentionally excludes internal phase-by-phase development notes, temporary qualification scripts and release-roadmap artifacts.
